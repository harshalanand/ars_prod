# 2026-10-14

## Module removal (ars_v4, committed on branch for_merge, not deployed)
- **Removed six modules** from the app: Contribution %, Auto Cont %, ALC_Fixture, Trends, Project Tracker, Training Manual viewer. Routers, endpoints, pages, nav entries and routes went together. [[Frontend Map]] · [[Platform and Infrastructure]]
- **ALC_Fixture correction:** it was a frontend-only placeholder. It was never the UI of [[Allocation Engine v2 (score-based)]], which is untouched. Earlier notes that said otherwise were wrong.
- **Contribution % never fed allocation.** Allocation CONT comes from uploaded `Master_CONT_<dim>`. [[Contribution and CONT]]
- **UPC Store Tracking** never read `TREND_ST`. It reads `ARS_GRID_MJ` summed per store, so removing Trends does not affect it. [[Dashboards Trends and Admin Tools]]
- **Kept:** the `public/docs/manual/*.md` dossiers (spec and Claude memory). `/listing/contribution` (Listing chart) stays.
- **Deploy-order gotcha:** deploy first, then run `backend/scripts/040_retire_removed_modules.sql`. Running it before the new code is live lets the old startup seed re-create and re-grant `MOD_*` to all roles. Part 3 only generates DROPs for review.
- **Security:** deleted `scripts/load_review_findings.py` had a hardcoded sa SQL password. It is still in git history. Rotation recommended.
