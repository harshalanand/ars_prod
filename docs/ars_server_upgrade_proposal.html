Recommendation

Option C if the existing server qualifies, otherwise option A.

Upgrading the existing app server saves about ₹15–20 L compared with new hardware, because it reuses the server we already own. It qualifies if it has at least 24 cores, can take 256 GB or more of ECC memory, has 6 or more free drive bays, and is under warranty or can be extended. Running the app and database on one machine needs firm memory limits for each, and good offsite backups, since one fault takes both down.

If it doesn't qualify, buy option A. It costs only ₹2–4 L more than B, and keeps the app and database apart. All options are sized for about 3 years at 2× today's load.

Next steps

  1. This week: run the capacity check on the existing app server (a read-only script, about 1 minute).
  2. If it qualifies, get a Lenovo quote for the memory and SSD upgrade. If not, get quotes for option A or B (ThinkSystem SR650 V3 / SR665 V3 or similar).
  3. Get SQL Server Standard quotes from a Microsoft licensing partner, per-core and Server + CAL. The per-core price depends on the final server's core count.
  4. This week, at no cost: take a full compressed backup, cap SQL's memory, and turn on backup compression.
  5. Migrate over one weekend, compressing the large history tables during the move. The current DB PC then becomes the dev/test database, where the free edition is allowed.
